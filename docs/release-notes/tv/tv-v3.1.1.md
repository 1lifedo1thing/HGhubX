# HGhubX TV tv-v3.1.1

HGhubX TV 3.1.1 正式版（`com.hghubx.tv`）：修复安卓 TV 视频源设置页遥控器方向右键无法选中后续操作按钮的问题，并包含 3.1 系列片尾预热、网络加速与 HEVC 自动回退。

## 修复
1. **视频源页面遥控器右键无法选中「停用」之后的操作按钮（#306）**：进入「设置 → 视频源」时遥控器只能聚焦到「停用/启用」，按右键无法移动到「测试」「更新」「回滚」「移除」 -> 将每个视频源条目改为独立横向焦点区，支持左右键顺畅遍历整行操作按钮、上下键跨视频源切换以及最左侧按左键返回设置分组栏。
2. **TV 端 HEVC 解码失败自动回退默认线路（#286、#296）**：不支持 HEVC MSE 解码的 32 位 ARM 电视盒子进入播放即黑屏报错 -> 自动保留当前进度切回默认线路、持久化线路偏好并展示非阻塞提示。

## 新增与优化
1. **片尾自动预热下一集首片（#299）**：播放临近片尾时自动并发预热下一集 HLS 播放列表与首片，遥控切集与自动连播接近秒开。
2. **网络复用与视频加载提速（#303）**：底层启用 HTTP/2 连接复用、延长客户端连接池生命周期、缓存系统代理探测、合并并发 HLS 清单请求并将封面解密移至后台线程池。

## 安装与兼容提示
- Android TV 按 ABI 分包提供 `HGhubX-TV_3.1.1_arm64.apk`、`HGhubX-TV_3.1.1_arm.apk`、`HGhubX-TV_3.1.1_x86_64.apk`（`com.hghubx.tv`，`versionCode=3001001`）。
- 沿用既有签名证书与版本序列，支持从 `tv-v3.0.0` / `tv-v3.1.0` 直接覆盖安装并保留已导入视频源、本机片库、观看记录、启动 PIN 与偏好设置。
