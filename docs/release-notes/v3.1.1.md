# HGhubX v3.1.1

HGhubX 3.1.1 正式版（替代撤回的 3.1.0）：包含 3.1 系列全量流畅度与视频加载性能优化、片尾下一集预热、AI 画质增强、桌面深链与底栏跟随手势切换，并进一步修复评论显示/计数异常与切页闪烁问题；覆盖 Windows、macOS、Linux、Android 与 iOS。

## 新增与优化
1. **全量流畅度与视频加载优化（#303）**：底层网络启用 HTTP/2 连接复用、延长客户端连接池生命周期并缓存系统代理探测，合并并发 HLS 清单请求且将封面解密移至后台线程池；前端收紧移动端播放缓冲策略、启用首片预取与按尺寸自适应码率，离页 20 秒自动挂起闲置解码器，并降低毛玻璃重绘与微光采样开销。
2. **片尾预热下一集与推荐流预加载（#299）**：播放临近片尾时自动并发预热下一集 HLS 清单与首片，首页推荐流在当前视频稳定播放 3 秒后同步预热下一条推荐视频，切集与切流接近秒开。
3. **AI 画质增强与 WebGL 渲染优化（#279、#281）**：新增「画质增强」播放设置，支持细节增强与自然胶片颗粒；通过 FBO 缓存、`texSubImage2D` 逐帧上传与 `ResizeObserver` 尺寸监听消除逐帧同步 GPU 检查带来的卡顿。
4. **移动端底栏跟随手势滑动（#292）**：在底部导航胶囊上左右滑动时实时带动主页面跟随切换；滑动期间自动暂停后台视频并合并逐帧位移写入以保持跟手顺滑。
5. **桌面端 `hghubx://` 深链与单实例转发（#282）**：Windows、macOS 与 Linux 注册 `hghubx://` 协议并在单实例间转发深链导入请求。
6. **首页跨页随机推荐与去重（#290）**：记录各视频源已知总页数并按未观看优先跨页随机采样，减少刷首页重复条目；再次点击底部「首页」按钮可直接刷新推荐流。
7. **图文帖子页直达首个分类（#294）**：移除冗余的「全部」标签，进入后默认展示首个源分类并支持左右滑动切类。
8. **「我的」页面下拉刷新收束（#289）**：移除重复的「刷新收藏」按钮并将下拉刷新手势收束至列表有效区。

## 修复
1. **评论面板与评论计数显示异常**：修复无评论空态偏上与误用心形图标、评论输入栏贴边挤压弹层圆角及浅色分割线/按钮对比度不足；兼容 `counts.comment` / `comment_count` 与数字字符串并避免分页返回 `total: 0` 时覆盖实际已加载评论数；补齐特殊昵称兜底与弹层挂载容器可见性校验。
2. **切换页面与底栏滑动闪烁**：修复底栏滑动落定前提前清理位移导致的离场页回闪、滑块拖拽抢写、重点击或二级页返回重播入场动画，以及切页起始透明度过低引发的露底闪烁。
3. **「我的」页面资料卡在多收藏时显示异常（#289）**：收藏超出首屏时顶部资料卡与分段栏被挤压变形 -> 增加独立弹性内容容器并锁定资料卡与头部控件高度不收缩。
4. **横屏全屏选集与详情弹层位置错误（#305）**：横屏或强制旋转全屏播放时，选集、详情、评论与更多弹层仍从竖屏底部弹出 -> 统一挂载至当前可见横屏播放舞台内，并以右侧抽屉形态展开。
5. **多选项胶囊切换特效冲出边界（#300）**：含多个选项的分段胶囊与移动底栏跨多格切换时滑块冲出外缘再弹回 -> 改用无过冲平滑曲线并约束胶囊容器裁剪边界。
6. **图文帖子与评论时间显示异常（#304）**：秒级/毫秒级时间戳或零值占位导致日期错乱 -> 统一按本地时区格式化并过滤无效零值，同时在切换内联视频片段时重置播放进度。
7. **移动端触觉反馈滚动误触（#298）**：列表滚动时触发多余震动 -> 仅在完成有效点击及胶囊滑动切换时震动。
8. **Linux WebKitGTK 播放首帧卡死（#291、#297）**：Linux WebKitGTK 硬件解码下开启微光采样导致黑屏无响应 -> 自动在 Linux WebKitGTK 禁用微光采样并隐藏对应设置开关。
9. **「全部标签」页 0 作品标签回退（#271、#293）**：恢复渲染前非空探测与本地缓存，手动刷新时强制重探。
10. **分类页频道标题行与搜索页热门作者误触（#295、#301）**：分类页频道标题行仅保留「全部」按钮可点击；搜索页热门作者移除长按关注，仅在作者页保留长按关注/取消关注。
11. **收藏筛选菜单 `Escape` 键偶发无法关闭（#288）**：改为文档捕获阶段监听 `Escape` 并归还焦点至触发按钮。

## 安装与兼容提示
- Windows 提供 NSIS 安装包与便携压缩包；macOS 提供 Universal DMG；Linux 提供 amd64 `.deb` 与 `.rpm`；Android 提供按 ABI 分包签名 APK（`versionCode=3001001`）；iOS 提供已 ad-hoc 签名的 `.ipa`（需自行重签侧载安装）。
- 支持从 `v3.0.0` 直接覆盖安装，所有已导入的视频源、收藏、观看记录与偏好设置均予保留。
